**Kiểm thử website bán hàng Sweet Shop**

Dự án cá nhân về kiểm thử thủ công cho website Sweet Shop, tập trung vào giỏ hàng và thanh toán.

**Mục tiêu kiểm thử**
Xác nhận luồng giỏ hàng, giao hàng, khuyến mãi, thanh toán và xác nhận đơn hàng hoạt động đúng; phát hiện và báo cáo lỗi để đánh giá mức độ sẵn sàng phát hành.

**Phạm vi****
Trong phạm vi: giỏ hàng, phương thức giao hàng và tổng tiền, mã khuyến mãi, địa chỉ thanh toán, thông tin thẻ, xác nhận đơn hàng, giao diện.
Ngoài phạm vi: hiệu năng, bảo mật chuyên sâu, trình duyệt khác và di động, kiểm thử tự động.
Môi trường: Windows 11, Microsoft Edge.
Vai trò

**Tester (cá nhân)**: thiết kế 102 test case, thực thi, báo cáo 20 lỗi, lập Test Report và Bug Report.

**Công cụ**

Qase (test case, test run, defect), Google Sheets (tổng hợp kết quả).
